# Glossary

## General

**User console** — The service management panel at `console.novin.cloud`.

**Zone** — The physical location hosting a service in a given geographic region.

**Wallet** — A shared Rial credit balance used across all services.

## Cloud servers

**Virtual machine (VM)** — A cloud server with dedicated resources.

**Image** — A ready-made operating system version that a server is created from.

**Plan (Instance Type)** — A predefined combination of CPU, memory, and disk.

**Snapshot** — A point-in-time image of a server's state for reverting back to later.

**cloud-init** — A mechanism for automatically running configuration on a Linux server's first boot.

**VNC** — Graphical access to a server's screen through the browser.

**Serial console** — Text-based access to a server, independent of the server's network.

## DNS

**DNS record** — An entry that specifies where a domain should point.

**Nameserver** — A server that answers DNS queries for a domain.

**TTL** — The amount of time (in seconds) a record's response stays cached.

**A record** — Points a domain to an IPv4 address.

**CNAME record** — An alias for another domain.

**MX record** — Specifies a domain's mail server.

**TXT record** — A text value, used for ownership verification or email configuration.

## CDN

**Gateway** — The core unit of the CDN service for a given site.

**Upstream** — The origin server that content is read from.

**Location** — A routing rule that maps a URL path to an upstream.

**Cache** — Temporary storage of content for faster responses.

**WAF** — Web application firewall, for protection against malicious traffic.

**TLS/SSL** — An encryption certificate for serving over `https`.

## AI

**Token** — A unit for counting text; the basis for calculating language model costs.

**API key** — A key that lets applications access the AI service.

**RPM / TPM** — The cap on requests and tokens per minute.
