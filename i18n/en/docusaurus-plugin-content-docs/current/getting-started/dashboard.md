# Getting to Know the User Console

The [user console](https://console.novin.cloud) is where you manage all of your services.

## Console sections

| Section | Purpose | Guide |
|---|---|---|
| **Cloud servers** | Create and manage virtual machines | [Guide](../cloud-servers/about.md) |
| **AI** | Access large language models | [Guide](../ai/about.md) |
| **DNS** | Manage domain records | [Guide](../dns/about.md) |
| **CDN** | Content delivery network and firewall | [Guide](../cdn/about.md) |
| **Wallet** | Balance, top-ups, and transactions | [Guide](../wallet/about.md) |
| **Tickets** | Contact support | [Guide](../support/tickets.md) |
| **Profile** | Account information and password | [Guide](../account/profile.md) |

## Sections in development

These services are shown in the console but aren't active yet:

- Kubernetes
- Cloud storage
- Networks
- Load balancers

## An important note about the wallet

All services are billed from a single **shared wallet**. Before creating any service, make sure your balance is sufficient.

To create a cloud server, you need at least **one-third of its monthly cost** available in your wallet.
