# Transactions

The wallet page has two tabs: **Top-up** and **Payments**.

## Top-up tab

The history of payments you've made to add balance:

| Column | Description |
|---|---|
| Date | Time of the transaction |
| Description | Payment identifier |
| Amount | Amount topped up |
| Tracking code | Bank tracking code |
| Status | Successful, pending, or failed |

**Filters:** You can filter by **status** and **date range**.

## Payments tab

Itemized charges deducted from the wallet for service usage:

| Column | Description |
|---|---|
| Date | Time the charge was recorded |
| Description | Server name or AI model name |
| Cost breakdown | Cost breakdown including tax |
| Amount | Amount deducted |
| Type | Server or AI |

Hovering over **Cost breakdown** shows the full breakdown:

- **Cloud server** — CPU, memory, network (download and upload), and disk, plus tax
- **AI** — input tokens, output tokens, total tokens, and amount

## Official invoices

:::note
Official invoices or billing statements are not currently available from the console. To request one, open a [support ticket](https://console.novin.cloud/dashboard/tickets) to the **Finance** department.
:::
