# Novin Cloud Wallet

All Novin Cloud services are billed from a single **shared Rial wallet**. Cloud servers, AI, CDN, and other services are all deducted from the same balance.

## Overview

```
   Wallet top-up                       Service usage
   (payment gateway)                  (server, AI, …)
         │                                    │
         ▼                                    ▼
   ┌────────────────────────────────────────────┐
   │            Wallet balance (Rial)            │
   └────────────────────────────────────────────┘
                        │
                        ▼
              Transaction history
        (top-ups and deducted charges)
```

## Currency

The wallet balance and all wallet amounts are displayed in **Rial**.

:::tip Rial or Toman?
**10 Rial** equals **1 Toman**. All amounts in the console are in Rial — keep this in mind when topping up.
:::

## Wallet sections

The [Wallet](https://console.novin.cloud/dashboard/wallet) page includes the following:

| Section | Description |
|---|---|
| **Current balance** | Your account's usable balance |
| **Add balance** | Top up your account via the payment gateway |
| **Gift code** | Use a gift code to add balance |
| **Top-up** | Your payment history |
| **Payments** | Itemized charges deducted for services |
