# Gift Code

If you've received a gift code, you can add it directly to your wallet balance.

## How to use it

1. Go to the [Wallet](https://console.novin.cloud/dashboard/wallet) page.
2. Click **"Have a gift code?"**.
3. Enter the code and click **"Use code"**.

On success, the amount is immediately added to your balance and a confirmation message shows the amount added.

## Possible errors

| Message | Meaning |
|---|---|
| This code was not recognized | The code was entered incorrectly or doesn't exist |
| This code has already been used or is no longer valid | The code has already been redeemed or has expired |
| Unable to use this code | A general error — try again later |

:::tip
Enter the code exactly as you received it. If the code includes a hyphen, include that too.
:::

If you're sure the code is valid but it's not being accepted, follow up via a [support ticket](https://console.novin.cloud/dashboard/tickets).
