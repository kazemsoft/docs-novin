# Registration and Login

## Account type

When you [register](https://console.novin.cloud/register), you choose one of two account types:

### Individual account

| Field | Description |
|---|---|
| First and last name | — |
| National ID | 10 digits, validated |
| Mobile number | In the format `09xxxxxxxxx` |
| Email | — |
| Password | See the requirements below |

### Legal entity account (company)

| Field | Description |
|---|---|
| Company name | — |
| National ID | — |
| Postal code | 10 digits |
| Registration number | — |
| Economic code | — |
| Address | — |
| Phone number | In the format `09xxxxxxxxx` |
| Email | — |
| Password | See the requirements below |

## Password requirements

The password must be at least **8 characters** and include all four of the following:

- An uppercase English letter
- A lowercase English letter
- A digit
- A special character (such as `!` or `@`)

## Email verification

After registration, a verification email is sent to you. If you didn't receive it, you can click **Resend** from the verification page (with a 2-minute interval between requests). Also check your spam folder.

## Mobile number verification

:::warning This step is mandatory
After your first login, you can't use the console until you verify your mobile number.

1. Enter your mobile number.
2. Enter the 6-digit code sent via SMS.
3. Click **"Verify code"**.
:::

## Login

Sign in from the [login page](https://console.novin.cloud/login) with your **email and password**. Signing in with a **Google account** is also available.

## Forgot your password

From the login page, click on password recovery:

1. Enter your email and mobile number.
2. Enter the 6-digit code sent via SMS.
3. Set a new password (meeting the same requirements above).
