# ساخت سرور ابری

از بخش [سرورهای ابری](https://console.novin.cloud/dashboard/cloud-servers/list) روی ساخت سرور جدید کلیک کنید. فرایند ساخت یک ویزارد چندمرحله‌ای است.

## گام ۱ — موقعیت مکانی

کشور و سپس زون (Zone) موردنظر را انتخاب کنید. در حال حاضر فقط **ایران** فعال است.

## گام ۲ — سیستم‌عامل

ایمیج موردنظر را از بین توزیع‌های موجود انتخاب کنید. فهرست به‌صورت زنده بر اساس زون انتخابی خوانده می‌شود.

## گام ۳ — نوع سرور

دو مسیر وجود دارد:

### پلن آماده

جدولی از پلن‌های از پیش تعریف‌شده با مشخصات CPU، رم، دیسک SSD، پهنای باند و قیمت ساعتی. یکی را انتخاب کنید.

### منابع دلخواه

اگر از صفحه **ماشین‌حساب** وارد شوید، به‌جای جدول پلن‌ها، اسلایدرهای تعیین منابع نمایش داده می‌شود:

| منبع | بازه |
|---|---|
| پردازنده | ۱ تا ۳۲ هسته |
| حافظه (رم) | ۱ تا ۶۴ گیگابایت |
| دیسک | ۲۰ تا ۵۱۲ گیگابایت |
| پهنای باند | ۱۰۰ تا ۵۱۲۰۰ گیگابایت |

قیمت به‌صورت زنده با تغییر اسلایدرها به‌روز می‌شود.

## گام ۴ — افزونه‌ها

اگر پلن آماده انتخاب کرده‌اید، می‌توانید دیسک، پردازنده یا رم اضافه‌تر روی آن اضافه کنید.

:::note
با افزودن افزونه CPU یا رم، سرور شما از حالت «پلن آماده» خارج می‌شود و در بخش تغییر پلن به‌عنوان سرور با منابع دلخواه شناخته خواهد شد.
:::

## گام ۵ — پیکربندی

| فیلد | توضیح |
|---|---|
| **IPv4** | به‌صورت پیش‌فرض فعال است |
| **IPv6** | هنوز در دسترس نیست |
| **نام کاربری** | بر اساس سیستم‌عامل مقدار پیش‌فرض دارد |
| **رمز عبور** | رمز دسترسی به سرور |
| **نام سرور** | شناسه سرور در کنسول |

:::warning قوانین نام سرور
نام سرور باید:

- فقط شامل **حروف کوچک انگلیسی و عدد** باشد
- با **حرف** شروع شود (نه با عدد)
- حداکثر **۱۰ کاراکتر** باشد
- بدون فاصله و کاراکتر خاص (`@`، `-`، `_` و…) باشد

کاراکترهای غیرمجاز هنگام تایپ پذیرفته نمی‌شوند.
:::

## گام ۶ — تنظیمات پیشرفته (فقط لینوکس)

برای سیستم‌عامل‌های لینوکسی، امکان ویرایش `cloud-init` وجود دارد تا هنگام اولین بوت، دستورها یا تنظیمات دلخواه شما اجرا شود. این گام اختیاری است و مقدار واردشده پیش از ادامه، اعتبارسنجی `YAML` می‌شود.

## تایید و ساخت

در ستون کناری، خلاصه سفارش و **جمع کل ساعتی و ماهانه** نمایش داده می‌شود.

:::warning موجودی کیف پول
برای ساخت سرور باید دست‌کم **یک‌سوم مبلغ جمع کل ماهانه** در کیف پول شما موجود باشد. اگر موجودی کافی نباشد، دکمه ساخت به **«شارژ کیف پول»** تغییر می‌کند.
:::

پس از زدن **«تایید و ساخت سرور»**، به فهرست سرورها منتقل می‌شوید. ساخت سرور و آماده شدن سیستم‌عامل چند دقیقه طول می‌کشد.

## گام بعدی

سرور که به وضعیت **Running** رسید، می‌توانید [به آن متصل شوید](./access.md).
