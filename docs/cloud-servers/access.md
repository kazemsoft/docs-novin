# اتصال به سرور

پس از آنکه سرور به وضعیت **Running** رسید، چند راه برای اتصال دارید.

## SSH (لینوکس)

آدرس IP سرور را از فهرست سرورها کپی کنید:

```bash
ssh root@192.0.2.10
```

رمز عبوری که هنگام ساخت سرور تعیین کرده‌اید را وارد کنید.

:::tip امنیت بیشتر
پس از اولین ورود، کلید عمومی SSH خود را روی سرور قرار دهید و سپس ورود با رمز عبور را غیرفعال کنید:

```bash
ssh-copy-id root@192.0.2.10
```

سپس در فایل `/etc/ssh/sshd_config` مقدار `PasswordAuthentication` را روی `no` بگذارید و سرویس را ری‌استارت کنید.
:::

## RDP (ویندوز)

با Remote Desktop به آدرس IP سرور متصل شوید و با نام کاربری `administrator` و رمز عبور تعیین‌شده وارد شوید.

## کنسول تحت وب

اگر به هر دلیل دسترسی شبکه‌ای به سرور ندارید (مثلاً فایروال را اشتباه تنظیم کرده‌اید)، از کنسول تحت وب استفاده کنید. دو گزینه وجود دارد:

### VNC

نمایش گرافیکی صفحه سرور. برای ویندوز و همچنین مراحل نصب سیستم‌عامل مناسب است. دکمه ارسال `Ctrl+Alt+Del` نیز در این صفحه موجود است.

### کنسول متنی

دسترسی به کنسول سریال سرور. برای سرورهای لینوکسی مناسب است.

:::note در دسترس بودن کنسول
- کنسول و VNC فقط وقتی سرور در وضعیت **Running** است فعال می‌شوند.
- در صفحه جزئیات سرور، علاوه بر Running بودن، باید **ایجنت سرور** هم متصل شده باشد. تا آن زمان پیام «سیستم‌عامل در حال آماده‌سازی است» نمایش داده می‌شود.
- کنسول متنی برای سرورهای **ویندوزی** نمایش داده نمی‌شود؛ برای ویندوز از VNC استفاده کنید.
:::

## تغییر رمز عبور

در صفحه جزئیات سرور، گزینه **«تغییر رمز عبور»** وجود دارد. رمز جدید باید دست‌کم ۶ کاراکتر باشد.

:::warning
اعمال شدن رمز عبور جدید حدود **۲۰ ثانیه یا بیشتر** طول می‌کشد. بلافاصله پس از ثبت، تلاش برای ورود با رمز جدید ممکن است ناموفق باشد.
:::

## اتصال برقرار نمی‌شود

۱. **وضعیت سرور** را بررسی کنید؛ باید `Running` باشد.
۲. با **کنسول تحت وب** وارد شوید و بررسی کنید سرویس `sshd` بالا باشد.
۳. **فایروال داخل سرور** را بررسی کنید — مثلاً `ufw status` یا `iptables -L`.
۴. اگر رمز عبور را به‌تازگی تغییر داده‌اید، کمی صبر کنید و دوباره تلاش کنید.
