# تیکت و پشتیبانی

برای ارتباط با تیم نوین کلاود، از بخش [تیکت‌ها](https://console.novin.cloud/dashboard/tickets) در کنسول استفاده کنید.

## ثبت تیکت جدید

روی **«اضافه کردن تیکت جدید»** کلیک کنید و فرم را پر کنید:

| فیلد | توضیح |
|---|---|
| **دپارتمان** | بخش مرتبط با موضوع |
| **موضوع** | عنوان کوتاه، دست‌کم ۵ کاراکتر |
| **توضیحات** | شرح مسئله، دست‌کم ۲۰ کاراکتر |
| **فوریت** | کم، متوسط یا زیاد |
| **سرویس مربوطه** | اختیاری — انتخاب سرور یا سرویس مرتبط |
| **آپلود فایل** | اختیاری — پیوست فایل |

نام و ایمیل شما به‌صورت خودکار از پروفایل پر می‌شود.

## انتخاب دپارتمان

| دپارتمان | موارد مناسب |
|---|---|
| **فنی** | مشکل سرور، شبکه، DNS، CDN و سایر مسائل فنی |
| **مالی** | پرداخت، صورتحساب، شارژ کیف پول |
| **فروش** | سوال پیش از خرید، مشاوره سرویس |

## سطح فوریت

| سطح | چه زمانی |
|---|---|
| **کم** | سوال عمومی، درخواست راهنمایی |
| **متوسط** | مشکلی که کار را کند کرده ولی سرویس در دسترس است |
| **زیاد** | سرویس از کار افتاده یا مشکل فوری |

:::tip تیکت موثر بنویسید
برای پاسخ سریع‌تر، این موارد را در تیکت بنویسید:

- نام دقیق سرویس یا سرور (از فیلد **سرویس مربوطه** استفاده کنید)
- **متن کامل خطا** — نه توصیف آن
- زمان دقیق بروز مشکل
- کارهایی که تا الان امتحان کرده‌اید
:::

## وضعیت تیکت

| وضعیت | معنی |
|---|---|
| **پاسخ داده نشده** | تیکت ثبت شده و در انتظار بررسی است |
| **در حال رسیدگی** | کارشناس در حال بررسی است |
| **پاسخ داده شده** | پاسخ داده شده و منتظر بازخورد شماست |
| **پاسخ مشتری** | شما پاسخ داده‌اید و منتظر بررسی مجدد است |
| **بسته شده** | تیکت خاتمه یافته است |

## پاسخ به تیکت

با ورود به تیکت، تمام پیام‌ها به‌ترتیب زمانی نمایش داده می‌شود. از کادر پایین صفحه می‌توانید پاسخ بدهید و در صورت نیاز فایل پیوست کنید.

:::note تیکت بسته‌شده
پس از بسته شدن تیکت، امکان ارسال پیام جدید در آن وجود ندارد. اگر مشکل دوباره تکرار شد، تیکت جدیدی ثبت کنید و به شماره تیکت قبلی اشاره کنید.
:::
