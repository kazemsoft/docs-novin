# سرویس DNS نوین کلاود

با سرویس DNS نوین کلاود می‌توانید رکوردهای دامنه خود را از داخل [کنسول کاربری](https://console.novin.cloud/dashboard/dns) مدیریت کنید — بدون نیاز به پنل ثبت‌کننده دامنه.

## مفهوم کلی

دامنه شما نزد **ثبت‌کننده دامنه** (مثلاً ایرنیک یا هر ریجسترار دیگری) ثبت شده است. آنچه نوین کلاود انجام می‌دهد، **میزبانی رکوردهای DNS** آن دامنه است. برای این کار باید نام‌سرورهای دامنه را در پنل ثبت‌کننده، به نام‌سرورهای نوین کلاود تغییر دهید.

```
    ثبت‌کننده دامنه                نوین کلاود                  کاربر نهایی
   (ایرنیک و غیره)
         │                             │                           │
         │  نام‌سرورها به نوین          │                           │
         │  کلاود اشاره می‌کنند  ─────► │                           │
         │                             │  ◄──── درخواست example.ir │
         │                             │                           │
         │                             │  پاسخ از روی رکوردهای     │
         │                             │  تعریف‌شده شما ──────────► │
```

## مراحل کار

۱. **افزودن دامنه** — دامنه را در کنسول ثبت می‌کنید. وضعیت آن `در انتظار` می‌شود.
۲. **تنظیم نام‌سرور** — نام‌سرورهایی که کنسول نمایش می‌دهد را در پنل ثبت‌کننده دامنه وارد می‌کنید.
۳. **فعال‌سازی** — با دکمه «بررسی مجدد» وضعیت را بررسی می‌کنید. پس از تایید، وضعیت `فعال` می‌شود.
۴. **مدیریت رکوردها** — رکوردهای A، CNAME، MX و غیره را اضافه می‌کنید.

راهنمای گام‌به‌گام: [افزودن دامنه](./add-domain.md)

## رکوردهای پشتیبانی‌شده

در کنسول این نوع رکوردها قابل ساخت هستند:

| نوع | کاربرد |
|---|---|
| `A` | اتصال دامنه به یک آدرس IPv4 |
| `AAAA` | اتصال دامنه به یک آدرس IPv6 |
| `CNAME` | نام مستعار برای یک دامنه دیگر |
| `MX` | تعیین سرور ایمیل |
| `TXT` | مقدار متنی (تایید مالکیت، SPF، DKIM) |
| `SRV` | معرفی سرویس روی میزبان و پورت مشخص |

جزئیات هر نوع: [مدیریت رکوردها](./records.md)
