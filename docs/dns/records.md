# مدیریت رکوردهای DNS

پس از [فعال شدن دامنه](./add-domain.md)، از صفحه جزئیات دامنه می‌توانید رکوردها را مدیریت کنید.

## افزودن رکورد

روی **«افزودن رکورد»** کلیک کنید و این فیلدها را پر کنید:

| فیلد | توضیح |
|---|---|
| **نوع** | یکی از `A`، `AAAA`، `CNAME`، `MX`، `TXT`، `SRV` |
| **نام** | زیردامنه — مثلاً `www`. برای خود دامنه اصلی از `@` استفاده کنید |
| **مقدار** | مقصد رکورد (بسته به نوع: IP، دامنه، متن و…) |
| **TTL** | مدت اعتبار پاسخ در کش |
| **پروکسی** | فقط برای `A`، `AAAA` و `CNAME` نمایش داده می‌شود |

در فیلد **نام**، کاراکتر `*` (برای رکورد wildcard) و `@` (برای ریشه دامنه) نیز پذیرفته می‌شود.

## انواع رکورد

### A و AAAA

دامنه را به یک آدرس IP وصل می‌کنند. `A` برای IPv4 و `AAAA` برای IPv6.

```
نوع: A     نام: @      مقدار: 192.0.2.10
نوع: A     نام: www    مقدار: 192.0.2.10
```

مقدار این رکوردها اعتبارسنجی می‌شود؛ باید یک آدرس IP معتبر باشد.

### CNAME

دامنه را به دامنه دیگری ارجاع می‌دهد.

```
نوع: CNAME    نام: www    مقدار: example.ir
```

:::warning محدودیت CNAME
رکورد `CNAME` را نمی‌توان روی ریشه دامنه (`@`) ساخت. برای ریشه از رکورد `A` استفاده کنید.
:::

### MX

سرور دریافت ایمیل دامنه را مشخص می‌کند. مقدار می‌تواند شامل عدد اولویت باشد؛ عدد کوچک‌تر یعنی اولویت بالاتر.

```
نوع: MX    نام: @    مقدار: 10 mail.example.ir
```

### TXT

مقدار متنی؛ برای تایید مالکیت دامنه، `SPF`، `DKIM` و `DMARC` استفاده می‌شود.

```
نوع: TXT    نام: @    مقدار: v=spf1 include:_spf.example.ir ~all
```

اگر فیلد نام را برای رکورد `TXT` خالی بگذارید، به‌صورت خودکار `@` در نظر گرفته می‌شود.

### SRV

میزبان و پورت یک سرویس مشخص را معرفی می‌کند.

## مقدار TTL

TTL تعیین می‌کند پاسخ یک رکورد چند ثانیه در کش سرورهای DNS بماند. گزینه‌های موجود:

| گزینه | ثانیه |
|---|---|
| ۱ دقیقه | ۶۰ |
| ۲ دقیقه | ۱۲۰ |
| ۵ دقیقه | ۳۰۰ |
| ۱۰ دقیقه | ۶۰۰ |
| ۱۵ دقیقه | ۹۰۰ |
| ۳۰ دقیقه | ۱۸۰۰ |
| ۱ ساعت | ۳۶۰۰ |
| ۲ ساعت | ۷۲۰۰ |
| ۱۲ ساعت | ۴۳۲۰۰ |
| ۱ روز | ۸۶۴۰۰ |

مقدار پیش‌فرض هنگام ساخت رکورد جدید، **۱ دقیقه** است.

:::tip انتخاب TTL
پیش از جابه‌جایی سرور، TTL را چند ساعت قبل روی مقدار کم (۱ تا ۵ دقیقه) بگذارید تا تغییر IP سریع منتشر شود. پس از پایدار شدن، می‌توانید آن را بالا ببرید تا فشار روی DNS کمتر شود.
:::

## حالت پروکسی

برای رکوردهای `A`، `AAAA` و `CNAME` یک کلید **پروکسی** نمایش داده می‌شود:

- **فقط DNS** — پاسخ DNS مستقیماً IP سرور شما را برمی‌گرداند.
- **پروکسی فعال** — ترافیک از شبکه نوین کلاود عبور می‌کند و IP اصلی سرور پنهان می‌ماند.

برای سایر انواع رکورد (`MX`، `TXT`، `SRV`) این گزینه معنا ندارد و نمایش داده نمی‌شود.

## ویرایش و حذف

هر رکورد در فهرست، دکمه‌های **«ویرایش»** و **«حذف»** دارد. تغییرات پس از انتشار در شبکه DNS اعمال می‌شوند؛ زمان انتشار به مقدار TTL قبلی همان رکورد بستگی دارد.
