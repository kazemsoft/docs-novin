# کد هدیه

اگر کد هدیه دریافت کرده‌اید، می‌توانید آن را مستقیماً به موجودی کیف پول خود اضافه کنید.

## نحوه استفاده

۱. به صفحه [کیف پول](https://console.novin.cloud/dashboard/wallet) بروید.
۲. روی **«کد هدیه دارید؟»** کلیک کنید.
۳. کد را وارد کنید و **«استفاده از کد»** را بزنید.

در صورت موفقیت، مبلغ بلافاصله به موجودی شما اضافه می‌شود و پیام تاییدی با مبلغ اضافه‌شده نمایش داده می‌شود.

## خطاهای احتمالی

| پیام | معنی |
|---|---|
| این کد شناسایی نشد | کد اشتباه وارد شده یا وجود ندارد |
| این کد قبلاً استفاده شده یا دیگر معتبر نیست | کد قبلاً مصرف شده یا تاریخ اعتبارش گذشته است |
| استفاده از این کد ممکن نشد | خطای عمومی — بعداً دوباره تلاش کنید |

:::tip
کد را دقیقاً همان‌طور که دریافت کرده‌اید وارد کنید. اگر کد شامل خط تیره است، آن را هم وارد کنید.
:::

اگر مطمئن هستید کد معتبر است ولی پذیرفته نمی‌شود، از طریق [تیکت پشتیبانی](https://console.novin.cloud/dashboard/tickets) پیگیری کنید.
