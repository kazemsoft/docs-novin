# کیف پول نوین کلاود

تمام سرویس‌های نوین کلاود از یک **کیف پول ریالی مشترک** هزینه می‌شوند. سرور ابری، هوش مصنوعی، CDN و سایر سرویس‌ها همگی از همین موجودی کسر می‌شوند.

## مفهوم کلی

```
   شارژ کیف پول                       مصرف سرویس‌ها
   (درگاه پرداخت)                    (سرور، هوش مصنوعی، …)
         │                                    │
         ▼                                    ▼
   ┌────────────────────────────────────────────┐
   │            موجودی کیف پول (ریال)            │
   └────────────────────────────────────────────┘
                        │
                        ▼
              تاریخچه تراکنش‌ها
        (شارژ‌ها و هزینه‌های کسرشده)
```

## واحد پول

موجودی و تمام مبالغ کیف پول به **ریال** نمایش داده می‌شود.

:::tip ریال یا تومان؟
هر **۱۰ ریال** برابر **۱ تومان** است. مبالغ کنسول همگی به ریال هستند — هنگام شارژ به این نکته دقت کنید.
:::

## بخش‌های کیف پول

صفحه [کیف پول](https://console.novin.cloud/dashboard/wallet) شامل این موارد است:

| بخش | توضیح |
|---|---|
| **موجودی فعلی** | مبلغ قابل استفاده حساب شما |
| **افزایش موجودی** | شارژ حساب از طریق درگاه پرداخت |
| **کد هدیه** | استفاده از کد هدیه برای افزایش موجودی |
| **شارژ** | تاریخچه پرداخت‌های شما |
| **پرداخت** | ریز هزینه‌های کسرشده بابت سرویس‌ها |
