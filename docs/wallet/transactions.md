# تراکنش‌ها

صفحه کیف پول دو تب دارد: **شارژ** و **پرداخت**.

## تب شارژ

تاریخچه پرداخت‌هایی که برای افزایش موجودی انجام داده‌اید:

| ستون | توضیح |
|---|---|
| تاریخ | زمان تراکنش |
| توضیحات | شناسه پرداخت |
| مبلغ | مبلغ شارژشده |
| کد رهگیری | کد پیگیری بانکی |
| وضعیت | موفق، در انتظار یا ناموفق |

**فیلترها:** می‌توانید بر اساس **وضعیت** و **بازه تاریخ** فیلتر کنید.

## تب پرداخت

ریز هزینه‌هایی که بابت مصرف سرویس‌ها از کیف پول کسر شده است:

| ستون | توضیح |
|---|---|
| تاریخ | زمان ثبت هزینه |
| توضیحات | نام سرور یا نام مدل هوش مصنوعی |
| جزئیات هزینه | تفکیک هزینه به‌همراه مالیات |
| مبلغ | مبلغ کسرشده |
| نوع | سرور یا هوش مصنوعی |

با نگه‌داشتن نشانگر روی **جزئیات هزینه**، تفکیک کامل نمایش داده می‌شود:

- **سرور ابری** — پردازنده، حافظه، شبکه (دانلود و آپلود) و دیسک، به‌علاوه مالیات
- **هوش مصنوعی** — توکن ورودی، توکن خروجی، مجموع توکن و مبلغ

## صورتحساب رسمی

:::note
در حال حاضر امکان دریافت فاکتور یا صورتحساب رسمی از کنسول وجود ندارد. برای دریافت صورتحساب، از طریق [تیکت پشتیبانی](https://console.novin.cloud/dashboard/tickets) و دپارتمان **مالی** درخواست دهید.
:::
