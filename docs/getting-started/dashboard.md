# آشنایی با کنسول کاربری

[کنسول کاربری](https://console.novin.cloud) مرکز مدیریت تمام سرویس‌های شماست.

## بخش‌های کنسول

| بخش | کاربرد | راهنما |
|---|---|---|
| **سرورهای ابری** | ساخت و مدیریت ماشین مجازی | [راهنما](../cloud-servers/about.md) |
| **هوش مصنوعی** | دسترسی به مدل‌های زبانی بزرگ | [راهنما](../ai/about.md) |
| **DNS** | مدیریت رکوردهای دامنه | [راهنما](../dns/about.md) |
| **CDN** | شبکه توزیع محتوا و فایروال | [راهنما](../cdn/about.md) |
| **کیف پول** | موجودی، شارژ و تراکنش‌ها | [راهنما](../wallet/about.md) |
| **تیکت‌ها** | ارتباط با پشتیبانی | [راهنما](../support/tickets.md) |
| **پروفایل** | اطلاعات حساب و رمز عبور | [راهنما](../account/profile.md) |

## بخش‌های در دست توسعه

این سرویس‌ها در کنسول نمایش داده می‌شوند اما هنوز فعال نیستند:

- کوبرنتیز
- فضای ذخیره‌سازی ابری
- شبکه‌ها
- لود بالانسر

## نکته مهم درباره کیف پول

تمام سرویس‌ها از یک **کیف پول مشترک** هزینه می‌شوند. پیش از ساخت هر سرویسی، از کافی بودن موجودی خود مطمئن شوید.

برای ساخت سرور ابری، باید دست‌کم **یک‌سوم هزینه ماهانه** آن در کیف پول موجود باشد.
