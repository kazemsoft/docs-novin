# سرویس CDN نوین کلاود

سرویس CDN نوین کلاود ترافیک سایت شما را از شبکه نوین کلاود عبور می‌دهد تا سرعت بارگذاری بیشتر شود، بار سرور اصلی کاهش یابد و لایه‌ای از محافظت روی سرویس شما قرار گیرد.

## مفاهیم پایه

| مفهوم | توضیح |
|---|---|
| **گیت‌وی (Gateway)** | واحد اصلی سرویس؛ هر سایت یا سرویس شما یک گیت‌وی دارد |
| **سرچشمه (Upstream)** | سرور اصلی شما که محتوا از آنجا خوانده می‌شود |
| **لوکیشن (Location)** | قانون مسیریابی: کدام مسیر URL به کدام سرچشمه برود |
| **TLS** | گواهی SSL برای ارائه سرویس روی `https` |
| **فایروال (WAF)** | قوانین محافظت در برابر ترافیک مخرب |

```
    کاربر  ──►  گیت‌وی نوین کلاود  ──►  سرچشمه (سرور شما)
                       │
                 ┌─────┴─────┐
                 │           │
              کش محتوا    فایروال
```

## نحوه کار

۱. یک **گیت‌وی** بسازید.
۲. **سرچشمه** را معرفی کنید (آدرس سرور اصلی شما).
۳. **لوکیشن** تعریف کنید تا مشخص شود کدام مسیر به کدام سرچشمه برود.
۴. در صورت نیاز، قوانین **فایروال** اضافه کنید.
