# فهرست کامل مخزن‌ها

در ادامه همه‌ی مخزن‌های عمومی (virtual) میرور نوین کلاود آمده است.
مخزن virtual یک آدرس واحد است که پشت صحنه هم کش محلی و هم منبع بالادستی را پوشش می‌دهد —
همین آدرس‌ها را در تنظیمات خود قرار دهید.
