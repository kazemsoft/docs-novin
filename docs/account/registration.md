# ثبت‌نام و ورود

## نوع حساب

هنگام [ثبت‌نام](https://console.novin.cloud/register) یکی از دو نوع حساب را انتخاب می‌کنید:

### حساب حقیقی

| فیلد | توضیح |
|---|---|
| نام و نام خانوادگی | — |
| کد ملی | ۱۰ رقم، اعتبارسنجی می‌شود |
| شماره موبایل | با فرمت `09xxxxxxxxx` |
| ایمیل | — |
| رمز عبور | شرایط پایین را ببینید |

### حساب حقوقی (شرکت)

| فیلد | توضیح |
|---|---|
| نام شرکت | — |
| شناسه ملی | — |
| کد پستی | ۱۰ رقم |
| شماره ثبت | — |
| کد اقتصادی | — |
| آدرس | — |
| شماره تماس | با فرمت `09xxxxxxxxx` |
| ایمیل | — |
| رمز عبور | شرایط پایین را ببینید |

## شرایط رمز عبور

رمز عبور باید دست‌کم **۸ کاراکتر** باشد و شامل هر چهار مورد زیر:

- حرف بزرگ انگلیسی
- حرف کوچک انگلیسی
- عدد
- کاراکتر خاص (مانند `!` یا `@`)

## تایید ایمیل

پس از ثبت‌نام، ایمیل تایید برای شما ارسال می‌شود. اگر ایمیل را دریافت نکردید، از صفحه تایید می‌توانید **ارسال مجدد** را بزنید (با فاصله ۲ دقیقه بین هر درخواست). پوشه اسپم را هم بررسی کنید.

## تایید شماره موبایل

:::warning این مرحله اجباری است
پس از اولین ورود، تا زمانی که شماره موبایل خود را تایید نکنید، امکان استفاده از کنسول وجود ندارد.

۱. شماره موبایل را وارد کنید.
۲. کد ۶ رقمی پیامک‌شده را وارد کنید.
۳. روی **«تایید کد»** کلیک کنید.
:::

## ورود

از صفحه [ورود](https://console.novin.cloud/login) با **ایمیل و رمز عبور** وارد شوید. ورود با **حساب گوگل** نیز در دسترس است.

## فراموشی رمز عبور

از صفحه ورود روی بازیابی رمز عبور کلیک کنید:

۱. ایمیل و شماره موبایل خود را وارد کنید.
۲. کد ۶ رقمی پیامک‌شده را وارد کنید.
۳. رمز عبور جدید را (با همان شرایط بالا) تعیین کنید.
