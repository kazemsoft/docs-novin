# مدل‌ها

نوین کلاود به ده‌ها مدل زبانی از ارائه‌دهندگان مختلف دسترسی می‌دهد. همه آن‌ها از طریق یک API یکسان و با یک کلید در دسترس هستند.

فهرست زنده مدل‌ها در بخش **هوش مصنوعی → مدل‌ها** در [کنسول کاربری](https://console.novin.cloud/dashboard/ai/models) قابل مشاهده است.

:::info مشاهده مدل‌ها در کنسول
برای دیدن فهرست مدل‌ها در کنسول، ابتدا باید یک کلید API فعال داشته باشید و آن را از منوی بالای صفحه انتخاب کنید. فهرست مدل‌ها بر اساس دسترسی همان کلید نمایش داده می‌شود.
:::

## شناسه مدل

هر مدل یک **شناسه (Model ID)** دارد که در درخواست‌ها استفاده می‌شود. شناسه‌ها با الگوی `ارائه‌دهنده/نام-مدل` نوشته می‌شوند:

```json
{
  "model": "anthropic/claude-sonnet-4-5",
  "messages": [...]
}
```

:::warning
شناسه مدل باید **دقیقاً** مطابق فهرست باشد. `gpt-4o` بدون پیشوند `openai/` معتبر نیست و خطای `404` برمی‌گرداند.
:::

برای دریافت فهرست دقیق شناسه‌ها به‌صورت برنامه‌نویسی:

```bash
curl https://iapi.novin.cloud/v1/models \
  -H "Authorization: Bearer $NOVIN_API_KEY"
```

## مشخصات مدل‌ها

در کارت هر مدل در کنسول، این اطلاعات نمایش داده می‌شود:

### پنجره زمینه (Context Window)

حداکثر تعداد توکنی که مدل می‌تواند در یک درخواست پردازش کند — شامل **مجموع** پیام ورودی، تاریخچه گفتگو و پاسخ تولیدشده.

اگر مجموع از این حد بگذرد، درخواست با خطا مواجه می‌شود. برای گفتگوهای طولانی یا پردازش اسناد بزرگ، مدلی با پنجره زمینه بزرگ‌تر انتخاب کنید.

| اندازه پنجره | کاربرد تقریبی |
|---|---|
| ۶۴ هزار توکن | گفتگوهای معمولی، متون کوتاه |
| ۱۲۸ هزار توکن | اسناد بلند، کدهای بزرگ |
| ۲۰۰ هزار توکن | چند سند هم‌زمان، پروژه‌های کامل |
| ۱ میلیون توکن | کتاب، مخزن کد کامل |

:::note توکن چیست؟
توکن واحد پردازش متن در مدل‌هاست. به‌طور تقریبی هر توکن معادل سه تا چهار حرف در متن انگلیسی است. متن فارسی معمولاً توکن بیشتری نسبت به متن انگلیسی هم‌اندازه مصرف می‌کند.
:::

### قابلیت‌ها

هر مدل ممکن است این قابلیت‌ها را داشته باشد:

| قابلیت | توضیح |
|---|---|
| **بینایی** (Vision) | توانایی دریافت و تحلیل تصویر در کنار متن |
| **فراخوانی تابع** (Function Calling) | توانایی فراخوانی ابزارها و توابع تعریف‌شده توسط شما — پایه ساخت Agent |
| **استریمینگ** (Streaming) | ارسال پاسخ به‌صورت تدریجی و کلمه‌به‌کلمه |

### قیمت ورودی و خروجی

هر مدل دو قیمت جداگانه دارد:

- **قیمت ورودی** — برای توکن‌هایی که شما به مدل می‌فرستید (پیام و تاریخچه)
- **قیمت خروجی** — برای توکن‌هایی که مدل تولید می‌کند

قیمت خروجی معمولاً **سه تا پنج برابر** قیمت ورودی است.

:::info قیمت‌های به‌روز
قیمت‌ها ممکن است تغییر کنند. همیشه قیمت فعلی هر مدل را در [صفحه مدل‌ها در کنسول](https://console.novin.cloud/dashboard/ai/models) ببینید. اعداد این صفحه صرفاً برای مقایسه نسبی مدل‌ها آورده شده‌اند.
:::

## ارائه‌دهندگان و خانواده‌های مدل

### Anthropic — خانواده Claude

مدل‌های Claude در استدلال، نوشتن متن طولانی و کار با کد قوی هستند و پنجره زمینه ۲۰۰ هزار توکنی دارند.

| مدل | ویژگی |
|---|---|
| `anthropic/claude-opus-4` | قوی‌ترین مدل خانواده، برای کارهای پیچیده |
| `anthropic/claude-sonnet-4-5` | تعادل خوب بین کیفیت و هزینه |
| `anthropic/claude-haiku-4-5` | سریع و ارزان، برای کارهای ساده و حجم بالا |
| `anthropic/claude-3.5-haiku` | نسخه قبلی مدل سریع |

### OpenAI — خانواده GPT و o-series

| مدل | ویژگی |
|---|---|
| `openai/gpt-4o` | مدل چندمنظوره با پشتیبانی از تصویر |
| `openai/gpt-4o-mini` | نسخه سبک و ارزان `gpt-4o` |
| `openai/gpt-4-turbo` | نسل قبلی، همچنان قدرتمند |
| `openai/o1`، `openai/o3` | مدل‌های استدلالی برای مسائل ریاضی و منطقی پیچیده |
| `openai/o4-mini` | مدل استدلالی سبک‌تر |

:::tip مدل‌های استدلالی
مدل‌های o-series پیش از پاسخ، مراحل استدلال را طی می‌کنند. برای مسائل ریاضی، منطقی و برنامه‌نویسی پیچیده دقیق‌ترند، اما کندتر و گران‌ترند. برای سوالات ساده از آن‌ها استفاده نکنید.
:::

### Google — خانواده Gemini

مشخصه اصلی این خانواده، **پنجره زمینه بسیار بزرگ (بیش از یک میلیون توکن)** است — مناسب پردازش اسناد و مخازن کد حجیم.

| مدل | ویژگی |
|---|---|
| `google/gemini-2.5-pro` | قوی‌ترین مدل خانواده |
| `google/gemini-2.5-flash` | سریع با همان پنجره زمینه بزرگ |
| `google/gemini-2.5-flash-lite` | سبک‌ترین و ارزان‌ترین |

### Meta — خانواده Llama

مدل‌های متن‌باز با کیفیت خوب و قیمت مناسب.

| مدل | ویژگی |
|---|---|
| `meta-llama/llama-3.3-70b-instruct` | کیفیت خوب با هزینه متعادل |
| `meta-llama/llama-3.1-405b-instruct` | بزرگ‌ترین مدل خانواده |
| `meta-llama/llama-3.2-11b-vision-instruct` | پشتیبانی از تصویر |

### DeepSeek

مدل‌های اقتصادی با تمرکز بر استدلال و کدنویسی.

| مدل | ویژگی |
|---|---|
| `deepseek/deepseek-chat-v3.1` | ارزان‌ترین گزینه برای کارهای عمومی |
| `deepseek/deepseek-r1` | مدل استدلالی |
| `deepseek/deepseek-r1-distill-llama-70b` | نسخه سبک‌شده مدل استدلالی |

### Mistral

| مدل | ویژگی |
|---|---|
| `mistralai/mistral-large-2411` | مدل پرچم‌دار |
| `mistralai/codestral-2508` | تخصصی کدنویسی، پنجره زمینه ۲۵۶ هزار توکن |
| `mistralai/mistral-nemo` | سبک و ارزان |

### Qwen

| مدل | ویژگی |
|---|---|
| `qwen/qwen3-235b-a22b` | بزرگ‌ترین مدل خانواده |
| `qwen/qwen3-coder` | تخصصی کدنویسی |
| `qwen/qwen-plus` | اقتصادی برای کارهای روزمره |

## راهنمای انتخاب مدل

| نیاز شما | پیشنهاد |
|---|---|
| کارهای ساده با حجم بالا (دسته‌بندی، خلاصه‌سازی کوتاه) | مدل‌های سبک: `gpt-4o-mini`، `claude-haiku-4-5`، `gemini-2.5-flash-lite` |
| گفتگوی عمومی با کیفیت خوب | `gpt-4o`، `claude-sonnet-4-5`، `gemini-2.5-flash` |
| نوشتن متن طولانی و باکیفیت | `claude-sonnet-4-5`، `claude-opus-4` |
| کدنویسی | `codestral-2508`، `qwen3-coder`، `claude-sonnet-4-5` |
| مسائل ریاضی و منطقی پیچیده | `openai/o1`، `openai/o3`، `deepseek-r1` |
| پردازش سند بسیار بزرگ | خانواده `gemini-2.5` (پنجره یک‌میلیونی) |
| تحلیل تصویر | مدل‌های دارای قابلیت بینایی |
| کمترین هزینه | `deepseek-chat-v3.1`، `mistral-nemo`، `qwen-plus` |

:::tip روش عملی انتخاب
از یک مدل متوسط شروع کنید. اگر کیفیت پاسخ کافی بود، مدل ارزان‌تر را امتحان کنید تا به کمترین هزینه قابل قبول برسید. اگر کافی نبود، به مدل قوی‌تر بروید. آزمایش با [چت کنسول](./chat.md) سریع‌ترین راه مقایسه است.
:::

## فیلتر و جستجو

در صفحه مدل‌ها در کنسول می‌توانید فهرست را بر اساس **ارائه‌دهنده** و **قابلیت** فیلتر کنید یا نام مدل را جستجو کنید.
