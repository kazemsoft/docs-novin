# هوش مصنوعی نوین کلاود

سرویس هوش مصنوعی نوین کلاود یک **دروازه واحد (Gateway)** برای دسترسی به ده‌ها مدل زبانی بزرگ است. به‌جای اینکه برای هر ارائه‌دهنده حساب جداگانه بسازید، کلید بگیرید و صورتحساب ارزی پرداخت کنید، با **یک کلید API** و **پرداخت ریالی از کیف پول نوین کلاود** به همه مدل‌ها دسترسی دارید.

## چرا این سرویس؟

| بدون نوین کلاود | با نوین کلاود |
|---|---|
| حساب جدا برای هر ارائه‌دهنده | یک حساب کاربری |
| کلید API جدا برای هر سرویس | یک کلید برای همه مدل‌ها |
| نیاز به کارت اعتباری بین‌المللی | پرداخت ریالی از کیف پول |
| مشکل دسترسی از ایران | دسترسی مستقیم بدون واسط |
| کد متفاوت برای هر ارائه‌دهنده | یک API استاندارد سازگار با OpenAI |

## سازگاری کامل با OpenAI

مهم‌ترین ویژگی این سرویس، **سازگاری کامل با استاندارد OpenAI API** است. یعنی هر کتابخانه، فریم‌ورک یا ابزاری که با OpenAI کار می‌کند، تنها با تغییر دو مقدار به نوین کلاود متصل می‌شود:

```python
from openai import OpenAI

client = OpenAI(
    api_key="کلید-API-شما",              # کلید نوین کلاود
    base_url="https://iapi.novin.cloud/v1"  # آدرس نوین کلاود
)
```

همین. بدون تغییر یک خط دیگر از کد، حالا به تمام مدل‌ها دسترسی دارید. این یعنی LangChain، LlamaIndex، Cursor، Continue و هر ابزار دیگری که از OpenAI پشتیبانی می‌کند، بدون نیاز به افزونه خاصی کار می‌کند.

## مدل‌های در دسترس

مدل‌هایی از ارائه‌دهندگان مختلف در دسترس هستند:

- **Anthropic** — خانواده Claude (Opus، Sonnet، Haiku)
- **OpenAI** — خانواده GPT و مدل‌های استدلالی o‑series
- **Google** — خانواده Gemini با پنجره زمینه بسیار بزرگ
- **Meta** — خانواده Llama
- **DeepSeek** — مدل‌های چت و استدلالی
- **Mistral** — از جمله Codestral برای کدنویسی
- **Qwen** — از جمله Qwen Coder

فهرست کامل و به‌روز مدل‌ها به همراه قیمت و مشخصات، در صفحه [مدل‌ها](./models.md) و همچنین در بخش **مدل‌ها** در کنسول کاربری قابل مشاهده است.

:::tip
فهرست مدل‌ها به‌صورت زنده از دروازه خوانده می‌شود. برای دیدن دقیق‌ترین وضعیت، به [کنسول کاربری](https://console.novin.cloud/dashboard/ai/models) مراجعه کنید یا از endpoint استاندارد `/v1/models` استفاده کنید.
:::

## نحوه کار سرویس

```
        شما / برنامه شما
               │
               │  Authorization: Bearer sk-...
               ▼
    ┌──────────────────────┐
    │  iapi.novin.cloud    │   دروازه هوش مصنوعی
    └──────────┬───────────┘
               │
               ▼
      ارائه‌دهندگان مدل‌های AI
```

**دروازه (Gateway)** — تمام درخواست‌ها از `iapi.novin.cloud` عبور می‌کنند. این لایه مدل درخواستی را به ارائه‌دهنده مربوطه مسیریابی می‌کند، محدودیت‌های کلید شما را اعمال می‌کند و توکن‌های مصرفی را می‌شمارد.

**احراز هویت** — کلیدهای API به حساب کاربری شما گره خورده‌اند و از کنسول کاربری ساخته و مدیریت می‌شوند.

**محاسبه هزینه** — هزینه هر درخواست بر اساس توکن‌های ورودی و خروجی محاسبه و از کیف پول ریالی شما کسر می‌شود. جزئیات در صفحه [مصرف و صورتحساب](./usage-billing.md).

## دو راه استفاده

### ۱. از طریق API

برای استفاده در برنامه‌ها، اسکریپت‌ها و ابزارهای توسعه. یک کلید API بسازید و از آن استفاده کنید:

```bash
curl https://iapi.novin.cloud/v1/chat/completions \
  -H "Authorization: Bearer $NOVIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o",
    "messages": [{"role": "user", "content": "سلام!"}]
  }'
```

راهنمای کامل: [شروع سریع](./quickstart.md) و [مرجع API](./api-reference.md).

### ۲. از طریق رابط چت

اگر می‌خواهید بدون کدنویسی با مدل‌ها کار کنید، دو گزینه دارید:

- **چت داخل کنسول** — بخش [چت](https://console.novin.cloud/dashboard/ai/chat) در کنسول کاربری، برای گفتگوی سریع و آزمایش مدل‌ها. راهنما: [چت](./chat.md)
- **رابط چت اختصاصی** — [chat.novin.cloud](https://chat.novin.cloud) با امکانات کامل‌تر، ورود با همان حساب کاربری نوین کلاود

## نحوه پرداخت

هزینه‌ها **به‌ازای مصرف واقعی** محاسبه می‌شود — هیچ اشتراک ماهانه یا هزینه ثابتی وجود ندارد. شما فقط بابت توکن‌هایی که واقعاً مصرف می‌کنید پرداخت می‌کنید و هزینه از موجودی کیف پول ریالی کسر می‌شود.

قیمت هر مدل بر اساس **تعداد توکن ورودی** و **تعداد توکن خروجی** به‌صورت جداگانه محاسبه می‌شود. توکن خروجی معمولاً گران‌تر از توکن ورودی است.

:::warning موجودی کافی
اگر موجودی کیف پول شما کافی نباشد، درخواست‌ها با خطای `402` رد می‌شوند. پیش از استفاده، از شارژ بودن کیف پول خود مطمئن شوید.
:::
